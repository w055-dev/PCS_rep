# MyASCIIPaint — консольный редактор ASCII-арта

Консольный графический редактор для создания ASCII-арта с поддержкой слоёв, геометрических примитивов (линии, прямоугольники, эллипсы, заливка), Undo/Redo и экспорта в TXT, ANSI, CSV, JSON.

## Сборка вручную

```bash
# 1. Создать папку для сборки
mkdir build && cd build

# 2. Сгенерировать файлы сборки
cmake ..

# 3. Скомпилировать проект
cmake --build .
```

## Сборка в (Docker)

```bash
# Сборка и запуск контейнера
docker compose up --build -d

# Подключение к контейнеру
docker attach ascii-paint

# Выход из контейнера (без остановки)
Q
```

### Управление

#### Навигация по холсту

| Клавиша | Действие |
|---------|----------|
| `↑` (вверх) | Перемещение вверх на 1 ячейку |
| `↓` (вниз) | Перемещение вниз на 1 ячейку |
| `←` (влево) | Перемещение влево на 1 ячейку |
| `→` (вправо) | Перемещение вправо на 1 ячейку |

#### Рисование и инструменты

| Клавиша | Инструмент | Описание |
|---------|------------|----------|
| `P` | Карандаш | Рисует одиночный символ `#` |
| `E` | Ластик | Стирает символ (ставит пробел) |
| `L` | Линия | Рисует линию из `*` между двумя точками |
| `R` | Прямоугольник | Рисует рамку из `#` |
| `F` | Залитый прямоугольник | Рисует залитый прямоугольник |
| `O` | Эллипс | Рисует эллипс из `O` |
| `G` | Заливка | Заливает область символом `#` |

#### Выбор цвета

| Клавиша | Цвет |
|---------|------|
| `1` | Чёрный |
| `2` | Красный |
| `3` | Зелёный |
| `4` | Жёлтый |
| `5` | Синий |
| `6` | Пурпурный |
| `7` | Голубой |
| `8` | Белый |
| `9` | Ярко-зелёный |
| `0` | Ярко-жёлтый |

#### Управление слоями

| Клавиша | Действие |
|---------|----------|
| `+` / `=` | Добавить новый слой |
| `-` / `_` | Удалить текущий слой |
| `[` / `{` | Переключиться на предыдущий слой |
| `]` / `}` | Переключиться на следующий слой |

#### Отмена и повтор

| Клавиша | Действие |
|---------|----------|
| `Z` | Отменить последнее действие (Undo) |
| `Y` | Повторить отменённое действие (Redo) |

#### Экспорт и сохранение

| Клавиша | Формат | Назначение |
|---------|--------|------------|
| `S` | TXT | Сохранить как обычный текст |
| `A` | ANSI | Сохранить с ANSI-цветами |
| `C` | CSV | Сохранить как CSV для игр |
| `J` | JSON | Сохранить как JSON |
| `V` | ASCP | Сохранить проект (слои, цвета) |
| `I` | — | Загрузить проект ASCP |

#### Другие команды

| Клавиша | Действие |
|---------|----------|
| `Пробел` / `Enter` | Выполнить действие текущим инструментом |
| `Q` | Выход из программы |
